# 数字人通话（管理员预览）

1. 登录网站管理后台，进入「应用配置 → 数字人通话」。
2. 在「服务凭证与通话设置」填写与桌面版相同账号的 Vidu API Key。凭证通过现有的应用配置加密机制保存在服务端（需要设置 `TOOL_SETTINGS_SECRET` 或长度至少 32 的 `ADMIN_SESSION_SECRET`）。也可以在服务端设置 `VIDU_API_KEY`。
3. 在「人设与话术」粘贴原系统提示词，或导入桌面版导出的 TXT。在「形象与声音」点击「读取账号形象」选择已有形象，或填形象 ID / HTTPS 图片；「读取已有音色」会同时列出克隆音色和公共音色。需要创建新音色时，在「音色克隆」提供参考音频 HTTPS 链接。
4. 勾选「启用管理员预览」并保存。保持同一网站的管理员登录状态，打开官网小柴对话窗口，点击电话图标，然后点击「开始通话」。浏览器需要麦克风权限；不会采集摄像头。

网页使用 [实时数字人官方接入协议](https://platform.vidu.cn/vidu-stream/doc/s2-avatar/realtime/quick-start)。服务端持有 API Key 和控制连接，浏览器只接收入会凭证，通过 RTC 直接发布麦克风、订阅数字人音视频。关闭页面、挂断和超时都会结束会话。当前预览只允许管理员发起，每个服务进程最多一通。桌面端的配置文件和账号密钥不会自动读取；上述字段可在后台迁移。

如需在 Supabase 记录通话时间、结束状态和配置版本，执行 `supabase/avatar-calls.sql`。不会在 MySpace 数据库记录音视频或通话正文；通话期间麦克风音频会送至云服务用于识别。原有 Dify 文字聊天独立运行。
