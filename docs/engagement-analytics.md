# 页面 / 内容 / 访客监测

## 启用

1. 在已有 Supabase 项目的 SQL Editor 执行 `supabase/engagement-analytics.sql`（新项目先执行 `supabase/schema.sql`）。
2. 构建、重启站点；后台“站点检测”默认打开今天（北京时间）。
3. 正式网站上的新访问开始生成页面、作品和视频统计。开发环境默认不记数据；本机、自动化流量不会出现在“仅真人”结果中。

迁移只增加独立统计表、字段和函数，不重写作品，不删除已有数据。旧访问没有内容时长，无法从点击次数还原，不会自动补造。

## 内容编号和历史保留

- 根据后台条目的持久 `id` 自动生成内容编号，不维护当前作品白名单。新增、改名、重新排序和分类调整均无需修改埋点代码。
- 普通作品和 AI 作品共享作品编号空间，跨栏目迁移保留 `id`。诗签和作品列表中的同一首诗共用编号。
- 历史数据独立存放在 `portfolio_engagements`，**不关联作品表的删除操作**；一条阅读记录保留访问当时的标题。
- 删除作品后继续提供统计，后台标为“已删除 · 历史保留”。用新编号重新创建同名作品属于新作品。
- 删除访客概览/访问记录不会级联删除内容统计；访问关联变为 `null`，匿名访客编号、历史标题和各项时长继续保留。
- 本功能没有内容历史清空接口。数据库拥有者手动删表仍会丢数据，应在 Supabase 配置备份并定期验证恢复。
- 遗留无编号诗签/AI 作品读取时自动补充稳定编号，随下一次保存持久化；正常新增内容始终有持久编号。
- 视频编号包含去除签名后的媒体地址版本。同一作品更换视频后，旧视频观看记录仍独立保留。

## 口径

| 指标 | 计算 |
| --- | --- |
| 页面停留 | 当前虚拟页面可见时累计；作品详情遮挡页面时暂停 |
| 作品停留 | 作品/图片/诗签详情打开且页面可见时累计 |
| 视频观看 | 可见、进入视口、播放时间实际推进时累计；暂停/缓冲/拖动不计 |
| 平均停留 | 总停留 ÷ 打开次数，包含短暂打开 |
| 平均观看 | 实际观看总时长 ÷ 播放过的播放器打开次数 |
| 播放次数 | 一次打开播放器且发生实际播放算一次；暂停后继续不重复计数 |
| 完播率 | 实际观看覆盖视频内容至少 90% 的播放次数 ÷ 播放次数；拖到结尾不算完播 |
| 最远进度 | 播放头到达的最远位置，不等于真实观看覆盖率 |
| 独立访客 | 按现有匿名浏览器 visitorKey 去重；不是登录账号或精确自然人数 |

一秒采样、十五秒批量上报，隐藏页面/离开时补报；后台通知每三十秒检查一次。网络中断、浏览器直接终止仍可能损失尚未送达的一小段数据。
内容报告按每次打开的开始时间筛选，跨日的一次阅读归入开始日；各层级时长有包含关系，**不能把作品和视频时长相加当成整站时长**。
累计快照通过唯一 span ID 和数据库最大值更新去重，重试、乱序和离开时重复上报不增加次数或时长。
后台报告在数据库中按内容聚合后分页；访客轨迹按打开时间倒序分页。

## 真人访问提醒

已有浏览器/IP 规则识别为 human，且单次可见停留严格大于 120000ms；
最近活动在 30 分钟内时，后台页面可见期间弹出非阻塞提示。不是身份认证，不能绝对证明自然人。
同一浏览器通过本地存储按访问 ID + 创建时间去重，刷新也不会反复提醒；清空浏览器存储后会重新提醒。
未升级数据库时兼容旧访问数据，最近时间暂按访问创建时间筛选。

## 接入未来页面和应用

React 页面根节点：`data-analytics-page="稳定页面编号"`、`data-analytics-title="页面名称"`。
内容详情容器：`data-analytics-kind="work"`、`data-analytics-key="稳定内容编号"`、`data-analytics-title="内容名称"`。
原生 video 元素：`data-analytics-key="稳定内容编号"`、`data-analytics-title="视频名称"`。
仅显式标记的内容播放器计入视频统计，背景装饰视频不计。外站/跨域播放器需其官方播放事件 SDK，不假造播放时间。

独立应用在 body 添加 `data-analytics-app="应用编号"`，用 `data-view` 表示内部页面，并载入 `/analytics.js`。
万创核心已接入这一入口，新应用复用同一脚本即可；不采集应用的输入内容或 API 密钥。

## 数据库校验（隔离数据库，不连接生产库）

`server/engagement-analytics.test.ts` 测试格式校验、阈值与鉴权。
`server/engagement-sql.test.ts` 在 PGlite 中执行真实迁移和 SQL，验证重复/乱序快照、聚合平均、真人过滤、跨内容去重及删除后历史保留。
SQL 测试通过环境变量 `PGLITE_MODULE` 指向已安装的 `@electric-sql/pglite/dist/index.js`；未提供时明确跳过，不会连接真实 Supabase。
